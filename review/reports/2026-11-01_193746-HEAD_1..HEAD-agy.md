## Findings

### 1. Middle-initial validation rate increases by 15.8 percentage points for identical kept pairs, confounding the paper's claim of improved match quality

`changing-validator-confounds-match-quality-gain` · **MAJOR** · claims-vs-code · confidence: **verified** (traced in source)

**Where:** `replication/diagnostics/validation_by_link_status.do:35-52, replication/results/validation_by_link_status.tex:23-26, CODE/create_figures_SSHA2025.do:70-86, D:/repos/6638fa0fd89fbec05130caeb/DHTS-2026-10-12.tex:98, D:/repos/6638fa0fd89fbec05130caeb/DHTS-2026-10-12.tex:547-549`

**What the code does**  
The diagnostic shows that for kept links in the discordant sample (829,471 pairs linking the identical 1940 record to the identical 1930 record before and after), middle-initial validation rises from 63.4% (valKeptOldTarget) to 79.2% (valKeptTarget). This occurs because CODE/create_figures_SSHA2025.do:70-86 merges mi1940 from the Ancestry link file for validated_before and from the model link file for validated_after, altering the validator between the two evaluations.

**Why it matters**  
The paper claims at lines 98 and 547-549 that the validation rate increase from 65% to 84% represents a 28% increase in match quality demonstrating that the model recovers true links rather than spurious ones. Because link correctness cannot change for identical kept pairs, the 15.8 percentage point increase is driven by changes in 1940 middle-initial transcription rather than link quality.

**How to check**  
In temp.dta, run `tab validated_before validated_after if status==1 & congruent==0, missing`. Observe that 15.8% of identical pairs change validation status solely due to differing 1940 middle initials between link files.

**Suggested fix**  
Do not describe the 65% to 84% rise as an increase in link match quality or proof of recovering true matches over spurious matches. Either validate links against an independent middle-initial source held fixed across both specifications, or describe the metric as middle-initial agreement that conflates transcription differences with link quality.

### 3. 86.1% added-link validation rate applies only to a selected 20.3% subsample with observed initials, but committed macro reports full link count

`added-link-validation-rate-masks-missing-initials` · **MAJOR** · identification · confidence: **verified** (traced in source)

**Where:** `replication/diagnostics/validation_by_link_status.do:61-69, replication/results/validation_by_link_status.tex:31-32, replication/diagnostics/validation_by_link_status.log:344-346, D:/repos/6638fa0fd89fbec05130caeb/DHTS-2026-10-12.tex:547-549`

**What the code does**  
For added links in the target sample (`status==3 & congruent==0`), `summarize validated_after` calculates an 86.1% validation rate over 396,760 records with observable middle initials. However, line 68 outputs `repnum nAddedTarget = 1,953,052` from `count if status==3`, discarding the non-missing count r(N).

**Why it matters**  
Middle initial presence is not random and correlates with literacy, race, and socioeconomic status. The 86.1% agreement rate describes only 20.3% of added links; the remaining 79.7% (1.56 million links) cannot be validated by middle initials. Pairing `\valAddedTarget = 86.1` with `\nAddedTarget = 1,953,052` masks this missingness and invites claims that nearly 2 million added links are validated at 86%.

**How to check**  
Inspect replication/diagnostics/validation_by_link_status.log:344-346, which displays: `Target Added: links 1,953,052 with MI 396,760 validated 0.8611`. Compare this with validation_by_link_status.tex lines 31-32, where only nAddedTarget = 1,953,052 is output.

**Suggested fix**  
Output both the total link count and the count of links with observable middle initials (e.g., nAddedTargetWithMI = 396,760), along with the availability percentage (20.3%). When discussing validation of added links in the paper, explicitly disclose that the 86.1% rate applies only to the selected 20.3% subset with observable initials.
