## Findings

### 1. The new table is never run by the replication entry point

`cell-table-absent-from-replication-master` · **MAJOR** · replication · confidence: **verified** (traced in source)

**Where:** `MATCHING/fs_cells.do:183-221, replication/run_machineA.do:80-93`

**What the code does**  
`fs_cells.do` writes `MATCHING/results/fs_cells.tex`, but the master constructs `local scripts` exclusively from CODE scripts and runs each as `do "$REP_REPO/CODE/`s'.do"`; it never invokes `MATCHING/fs_cells.do`.

**Why it matters**  
Neither the documented full run nor `-SkipRebuild` regenerates or verifies this table. A stale, missing, or manually generated cell table can therefore reach the paper while the advertised replication run still succeeds.

**How to check**  
Run `rg -n "fs_cells\.do|fs_cells\.tex" replication MATCHING` and confirm that the only executable reference is inside `MATCHING/fs_cells.do` itself.

**Suggested fix**  
Add this script to the appropriate machine-A master stage, add all of its inputs to preflight, and include its generated table in the driver's changed-output checks.

### 2. Any unexpected state-file failure is silently recoded as “Not classified”

`failed-state-silently-becomes-unclassified` · **MAJOR** · correctness · confidence: **verified** (traced in source)

**Where:** `MATCHING/fs_cells.do:59-65, MATCHING/fs_cells.do:83-92, MATCHING/fs_cells.do:118-120`

**What the code does**  
The loop wraps `describe ... using ...` in `capture` and executes `continue` for every nonzero `_rc`. Records absent from the resulting `cells` tempfile are later assigned `cell = 0` through `replace cell = 0 if _merge==1`. There is no expected-success count or assertion distinguishing the intended Hawaii exception from any other missing, corrupt, or schema-incompatible state file.

**Why it matters**  
The overall Ancestry/ML gate does not depend on cell classification, so it can pass even when an entire unexpected jurisdiction has been moved into cell 0. The by-cell linkage and validation results would then be wrong without an error.

**How to check**  
Temporarily point one listed state at a missing copy, or rename one required variable in a disposable input copy, then run the script and observe that it proceeds to the table with those records in cell 0 rather than exiting.

**Suggested fix**  
Explicitly exempt only the documented Hawaii case, count successful jurisdictions, assert the expected count, and exit on any other `_rc`. Also tabulate and assert the expected unmatched target records after merging `cells`.
