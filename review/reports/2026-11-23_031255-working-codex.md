## Findings

### 1. Records left with no usable model name can retain `name_true_cleaned_exists==1`

`single-sentinel-empty-field-retains-model-flag` · **minor** · correctness · confidence: **verified** (traced in source)

**Where:** `MATCHING/1d_for_mlp_tgtns.do:25, MATCHING/1d_for_mlp_tgtns.do:108-110, MATCHING/1d_for_mlp_tgtns.do:138, MATCHING/1e_tgtns_divided_files.do:27-33`

**What the code does**  
The code flags cleaned sentinels with `sf` and `sl` but clears the existence indicator only with `replace name_true_cleaned_exists = 0 if sf & sl`. If one raw model field was `InvalidPred` and the other was empty, the upstream pipeline already replaced the empty field with Ancestry, so only one of `sf` or `sl` is visible here. Replacing that remaining sentinel with Ancestry leaves both output fields as fallbacks while the indicator remains 1, contrary to the line-25 description that it identifies target records with model names.

**Why it matters**  
The analogous ABE builder documents about 15,665 target records across both sexes with this pattern. The exact eligible count in this MLP export is unseen, but any downstream count or subgroup analysis conditioned on `name_true_cleaned_exists==1` will classify those fallback-only records as having model output. The saved linkage names themselves are unaffected if the external matcher ignores the flag.

**How to check**  
From the raw state model files, define `raw_none = inlist(lower(namefrst_ml),"","invalidpred") & inlist(lower(namelast_ml_ditto),"","invalidpred")`, retain those histids, merge them to `for_mlp1940_tgtns.dta`, and run `count if _merge==3 & name_true_cleaned_exists==1`. As a quick aggregate check, the committed diagnostic implies `3,375,771 + 298,969 - 3,659,075 = 15,665` target records with a sentinel in one field and an empty other field.

**Suggested fix**  
Carry field-level raw usability indicators into this build, or merge a histid-level mapping from the raw model files, and set `name_true_cleaned_exists` to whether either field remains genuinely model-supplied after treating the sentinel as unusable. If the variable instead means that a prediction row originally existed, rename or document that meaning and remove the claim that it identifies records with model names.
