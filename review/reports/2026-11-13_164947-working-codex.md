## Findings

### 1. The reproduction diagnostic never decides whether the Rhode Island results were reproduced

`ri-reproduction-check-has-no-pass-criterion` · **minor** · replication · confidence: **verified** (traced in source)

**Where:** `replication/diagnostics/ri_replication.do:36-79`

**What the code does**  
The script stores rounded August values in locals, recomputes current statistics, and only prints them through expressions such as `display ... `old_lb_`grp'' ... `lb'`. Its only assertions check that the state filter returns one nonempty state; there is no assertion or calculated tolerance comparing any current statistic with its August counterpart.

**Why it matters**  
The script can finish with a successful exit status even if every current rate or sample count differs materially from the historical result. It therefore provides an eyeball comparison but does not answer its stated question, “DOES THE CURRENT CODE REPRODUCE THE RHODE ISLAND RESULTS?”, in a repeatable way.

**How to check**  
Run `rg -n "assert|exit|old_lb|old_la|old_vb|old_va" replication/diagnostics/ri_replication.do`; the only assertions are the state-selection checks at lines 30-31, and the benchmark values are otherwise used only for display.

**Suggested fix**  
Define justified count and rate tolerances, preferably using unrounded historical values, calculate each old-versus-current difference, and assert or explicitly emit PASS/FAIL for every row. If changed links and sample definitions prevent a direct tolerance check, decompose those changes or rename the script as a descriptive comparison rather than a reproduction test.
