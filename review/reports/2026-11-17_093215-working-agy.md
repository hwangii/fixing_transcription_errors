## Findings

### 1. The diagnostic merges against target-only flags, misclassifying ~44 million labeled non-target records as absent from census1940_all_labeled_data

`target-only-flag-breaks-census-membership-diagnostic` · **BLOCKER** · correctness · confidence: **verified** (traced in source)

**Where:** `MATCHING/1c_tgt_divided_files.do:58-65, MATCHING/tgt_fallback_diag.do:18-21, MATCHING/tgt_fallback_diag.do:43-45, MATCHING/tgt_fallback_diag.do:75-77`

**What the code does**  
In 1c_tgt_divided_files.do:63, `keep if tgt` filters tgt_flag1940.dta to target IDs only (~35.5M records out of 122.6M in census1940_all_labeled_data.dta). tgt_fallback_diag.do:18-21 then loads this target-only file into ids and selects records with `_merge==1` at lines 43-44, claiming at line 77: '## Divided-file records not in census1940_all_labeled_data.dta: `nn''. Because `_merge==1` captures all divided-file records not in tgt_flag1940.dta, it absorbs ~44 million labeled records with `tgt==0` in addition to the 4,819,575 genuinely absent records.

**Why it matters**  
The diagnostic will report ~48.8 million records rather than 4.8 million records under the heading 'Divided-file records not in census1940_all_labeled_data.dta'. Its age breakdown and birthplace rankings will reflect ordinary non-target census records rather than the genuinely missing census records, completely distorting any identification assessment of selection into the target sample.

**How to check**  
In Stata, count records in tgt_flag1940.dta (it holds ~35.5M records, not 122.6M). Merge one divided file against tgt_flag1940.dta versus the full census1940_all_labeled_data.dta ID list; observe that _merge==1 against tgt_flag1940.dta includes all non-target records.

**Suggested fix**  
In tgt_fallback_diag.do, extract ids directly from histid in census1940_all_labeled_data.dta without filtering on tgt. Retain the keep if tgt optimization in 1c_tgt_divided_files.do for production matching speed, but do not use tgt_flag1940.dta as a proxy for labeled census membership.

### 2. Loop variable typo in nomatch accumulation uses zb instead of zn, causing tempfile overwrite or runtime crash

`typo-zb-instead-of-zn-in-nomatch-append` · **BLOCKER** · correctness · confidence: **verified** (traced in source)

**Where:** `MATCHING/tgt_fallback_diag.do:46-50`

**What the code does**  
At line 48 of MATCHING/tgt_fallback_diag.do, the code executes `if `zb'>1 append using `nomatch''. Here, `zb' is the counter for files with fallback discrepancies (bad), whereas `zn' is the counter for files with unmatched records (nomatch).

**Why it matters**  
If zb remains 0 or 1, `if `zb'>1` is never true; each file's unmatched records overwrite nomatch rather than appending, discarding all prior files and leaving nomatch with only the final file's records. Conversely, if zb > 1 before a subsequent file first encounters unmatched records (zn == 1), line 48 attempts to append to a nonexistent nomatch tempfile, crashing Stata with error 601 (file not found).

**How to check**  
Inspect lines 25-26 and 46-50 of MATCHING/tgt_fallback_diag.do; notice `local ++zn' at line 47 followed by `if `zb'>1 append using `nomatch'' at line 48.

**Suggested fix**  
Change line 48 to `if `zn'>1 append using `nomatch''.

### 3. Unconditional use of bad and nomatch tempfiles crashes if zero records qualify

`missing-zero-observation-guards-for-tempfile-use` · **minor** · correctness · confidence: **verified** (traced in source)

**Where:** `MATCHING/tgt_fallback_diag.do:56, MATCHING/tgt_fallback_diag.do:75`

**What the code does**  
At lines 37-41, `save `bad', replace` is executed only if `_N > 0`. If no records meet the discrepancy condition across all files, zb is 0 and bad is never created. Line 56 unconditionally executes `use `bad', clear`, which crashes Stata with error 601. Line 75 does the same for nomatch if zn is 0.

**Why it matters**  
Once the 436 fallback discrepancies are resolved or when testing on clean datasets, the diagnostic crashes with error 601 instead of writing a clean summary, leaving the markdown file handle open.

**How to check**  
Run tgt_fallback_diag.do on inputs where no fallback records differ; Stata aborts at line 56 with 'file __000001 not found'.

**Suggested fix**  
Guard lines 56-74 with `if `zb'>0 { ... } else { file write md \"No discrepant fallback records found.\" _n }` and lines 75-90 with `if `zn'>0 { ... } else { file write md \"No unmatched records found.\" _n }`.
