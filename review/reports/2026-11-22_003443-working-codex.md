## Findings

### 1. The reported “erosion” is raw-string disagreement, not a change in linkage inputs or links

`raw-disagreement-labeled-linkage-erosion` · **MAJOR** · claims-vs-code · confidence: **verified** (traced in source)

**Where:** `MATCHING/ditto_diag.do:101-108, MATCHING/ditto_diag.do:188-194, MATCHING/ditto_diag.do:351-380, MATCHING/1_divide_and_clean_everyoneV5_women_addedV2.do:112-123, MATCHING/1_divide_and_clean_everyoneV5_women_addedV2.do:154-173, MATCHING/results/ditto_diag_SMOKE.md:58-72`

**What the code does**  
The diagnostic defines `nt_diff = nt & ((namefrst_u!="" & namefrst_u!=namefrst) | (namelast_u!="" & namelast_u!=namelast))` and reports it as `Linked name changes on either field (the erosion)`. This compares raw strings after counterfactually converting `InvalidPred` to empty. The production pipeline instead deduplicates observations, excludes rows with missing `parsing_quality`, leaves the nonempty `InvalidPred` sentinel in the current pipeline, applies field-level fallback, and runs `abeclean` before linkage. Raw differences can therefore disappear during cleaning, and actual links additionally depend on candidate uniqueness and competing records.

**Why it matters**  
The Wyoming value of 8.27% is neither the share of production linkage names that change nor the share of links lost. Calling it erosion can misattribute the documented non-target linkage loss to transcription differences when the actual loss must be measured from cleaned inputs and before/after link transitions.

**How to check**  
For production non-target records, construct the Ancestry and model-plus-fallback names exactly as `1_divide_and_clean_everyoneV5_women_addedV2.do` does, including `parsing_quality`, sentinel behavior, and `abeclean`. Tabulate raw disagreement against cleaned-name disagreement, then merge the old and all-record link outputs by 1940 ID and count unchanged, lost, gained, and changed links.

**Suggested fix**  
Relabel `nt_diff` as raw transcription disagreement and remove “linked name changes” and “erosion,” or replace it with cleaned-name and actual link-transition measures. Report current sentinel-blind and proposed sentinel-aware pipelines separately.

### 2. Section 3 excludes production non-target records lacking four complete human name fields

`non-target-diagnostic-uses-narrower-sample-than-policy` · **MAJOR** · identification · confidence: **verified** (traced in source)

**Where:** `MATCHING/ditto_diag.do:61-66, MATCHING/ditto_diag.do:152-155, MATCHING/ditto_diag.do:182-194, MATCHING/1c_tgt_divided_files.do:17-19, MATCHING/1c_tgt_divided_files.do:47-65, MATCHING/1c_tgt_divided_files.do:96-114, MATCHING/tgt_fallback_diag.do:4-9, MATCHING/results/ditto_diag_SMOKE.md:11-18`

**What the code does**  
The diagnostic defines `nt = hc & namefrst==fs_namefrst & namelast==fs_namelast`, where `hc` requires all four human fields to be nonempty. The production policy instead builds its target flag without that completeness restriction and sets every divided-file record absent from the target-flag file to `tgt=0`; the existing diagnostic records 4,819,575 divided-file records absent from the labeled source and therefore treated as non-target. In the Wyoming smoke file, 71,797 of 304,640 records are outside both the HC target and HC non-target categories.

**Why it matters**  
The reported non-target disagreement rate cannot explain the all-record versus target-only linkage difference for the production population. Model-name changes among excluded records can directly alter their links and can also change candidate collisions for the human-complete records on which linkage outcomes are reported.

**How to check**  
Merge each `merged_data.dta` record to the actual `tgt_flag1940.dta` by `histid`, default unmatched records to policy non-target as in `1c_tgt_divided_files.do`, and tabulate `nt` against `!tgt_policy`. Recompute raw-name, cleaned-name, and link-transition results separately for HC consensus records, incomplete-human records, and records absent from the labeled file.

**Suggested fix**  
Use the production target flag to define the Section 3 denominator and report the current HC-consensus group as a subgroup. Include records absent from the labeled data and records with incomplete human names when diagnosing the policy-level loss.
