## Findings

### 1. The reported 28% match-quality gain changes the validator along with the treatment

`moving-validator-inflates-match-quality-gain` · **BLOCKER** · claims-vs-code · confidence: **verified** (traced in source)

**Where:** `CODE/create_figures_SSHA2025.do:70-83, CODE/create_figures_SSHA2025.do:203-220, replication/diagnostics/validation_fixed_initials.do:31-40, replication/results/validation_fixed_initials.tex:28-30, replication/results/validation_fixed_initials.tex:68-70, D:\repos\6638fa0fd89fbec05130caeb\DHTS-2026-10-12.tex:97-98, D:\repos\6638fa0fd89fbec05130caeb\DHTS-2026-10-12.tex:547-549`

**What the code does**  
The old-link file supplies its own `mi1940` to `validated_before=mi1930==mi1940`, while the new-link file separately supplies its own `mi1940` to `validated_after=mi1930==mi1940`. The diagnostic explicitly describes these as moving-validator rates (`vb_own` and `va_own`) because the 1940 initial changes with the transcription being evaluated. The paper nevertheless describes their 65%-to-84% difference as a 28% increase in match quality. Holding the validator fixed produces only 16.0% using Ancestry and 11.5% using FamilySearch in the stored diagnostic results.

**Why it matters**  
Part of the headline increase comes from changing how the validation outcome itself is read, not from recovering better links. Therefore the abstract, introduction, and main-results claim overstate the improvement in link quality; the reported result is not comparable before versus after as written.

**How to check**  
Run `replication/diagnostics/validation_fixed_initials.do`, then compare `valGainTarget` in `replication/results/create_figures_SSHA2025.tex` with `valGainAncTarget` and `valGainFsTarget` in `replication/results/validation_fixed_initials.tex`. Also tabulate `validated_before` versus `validated_after` for records with the same `id_A_before==id_A_after`; under a genuinely fixed validator these flags cannot change.

**Suggested fix**  
Use one pre-specified 1940 initial source for both versions in `create_figures_SSHA2025.do`, regenerate the table and prose, and report the alternative source as robustness. If the moving measure is retained, rename it as a joint transcription-plus-linkage measure and prominently decompose the 28% rather than calling the full amount improved match quality.

**Why it matters**

**How to check**
