## Findings

### 1. ABE and MLP use different records, ages, birthplaces, and first names

`abe-mlp-comparison-confounded-by-different-inputs` · **MAJOR** · identification · confidence: **verified** (traced in source)

**Where:** `MATCHING/extract_diff_diag.do:1-7, MATCHING/extract_diff_diag.do:19-22, MATCHING/check_mlp_abe_same_input.log:406-454, MATCHING/check_mlp_abe_same_input.log:806-816`

**What the code does**  
The new diagnostic explicitly assigns ABE to `divided_file<yr>` and MLP to `divided_file<yr>_women_added`, which derive from different IPUMS extracts. The existing final-input check reports 4,271 MLP men absent from ABE, 1,425 ABE men absent from MLP, 4,081 matched ABE records not coded male in MLP, plus 1,255,248 age, 608,934 birthplace, and 61,959 first-name differences, before exiting with `RUN-STATA-RC: 9`.

**Why it matters**  
Age and birthplace are blocking or matching variables and first name is a core linkage field. Consequently, any side-by-side ABE/MLP linkage-rate or quality difference combines algorithm effects with input-value and sample-composition effects; without the paper draft, this cannot be promoted to a blocker, but a referee would demand an identical-input comparison.

**How to check**  
Run `.\replication\Run-Stata.ps1 MATCHING\check_mlp_abe_same_input.do` and confirm the displayed universe counts and `d_age`, `d_bpl`, `d_f`, and `d_any` totals. After rebuilding, require zero unmatched men, zero nonmale matches, and `d_any==0` before comparing algorithms.

**Suggested fix**  
Build both ABE and MLP male inputs from one frozen extract and one common record universe, assert exact equality of histid, sex, age, birthplace, first name, surname, initial, and model-name flag, and then rerun both linkage methods. Until then, describe existing comparisons as jointly reflecting algorithm and input-source differences.

### 2. The age diagnostic omits missing and large gaps from its distribution and never lists age-only cases

`age-diagnostic-hides-important-cases` · **minor** · correctness · confidence: **verified** (traced in source)

**Where:** `MATCHING/extract_diff_diag.do:10-12, MATCHING/extract_diff_diag.do:74-83`

**What the code does**  
The code generates `dage = age_W - age_M if d_age`, but tabulates only `if inrange(dage,-12,12)`; the `missing` option cannot restore observations excluded by that qualifier, and `summarize dage` also excludes missing differences. The examples loop is `foreach x in f l mi bpl`, omitting `age` despite promising examples of each kind.

**Why it matters**  
A mismatch involving one missing age disappears from both the distribution and summary, while gaps outside ±12 have no reported frequency. Because age discrepancies are the largest documented input difference, the output cannot distinguish ordinary small discrepancies from missingness, coding changes, or likely record misalignment.

**How to check**  
After line 74, run `count if d_age & (missing(age_M) | missing(age_W))`, `count if d_age & !missing(dage) & !inrange(dage,-12,12)`, and, within `preserve`, `keep if d_age` followed by `list histid age_M age_W bpl_M bpl_W in 1/15`.

**Suggested fix**  
Report missing-on-either-side and outside-±12 counts explicitly, tabulate or bin the full nonmissing difference distribution, and add `age` to the examples loop.
