## Findings

### 1. The county analysis silently broadens the project’s no-schooling category to include nursery school

`county-no-schooling-definition-drift` · **MAJOR** · claims-vs-code · confidence: **verified** (traced in source)

**Where:** `CODE/compute_county_correlates.do:17-18, CODE/compute_county_correlates.do:34, CODE/compute_subgroup_linkage_rates.do:23-27, CODE/usa00589_for_rhode_island_socio_demo_char.do:3034-3036, D:/repos/6638fa0fd89fbec05130caeb/DHTS-2026-10-12.tex:750`

**What the code does**  
The new code defines `noed = inrange(higrade,1,3)`, so raw codes 1, 2, and 3 all count as no education. The script says this follows the existing `recode (1 3=1)`, but Stata interprets `1 3` as the two discrete values 1 and 3, not the range `1/3`; the existing subgroup analysis therefore excludes code 2 from its `higrade==1` no-schooling group. The repository’s value labels identify code 2 as “Nursery school.”

**Why it matters**  
The paper reports 29.9 versus 27.8 percent for counties split by the share “without formal schooling,” but those numbers use a broader education category than the paper’s other no-schooling results. Reclassifying code 2 changes county shares, the median split, and potentially both reported incongruence rates.

**How to check**  
In Stata, load `temp.dta` and run `tab higrade`, then reproduce the county calculation twice using `gen noed_new=inrange(higrade,1,3)` and `gen noed_existing=inlist(higrade,1,3)`. Compare the medians, county group assignments, and above/below incongruence means; also run `count if higrade==2` to quantify the affected records.

**Suggested fix**  
Choose and document one substantive definition. If consistency with the existing project grouping is intended, replace `inrange(higrade,1,3)` with `inlist(higrade,1,3)` and regenerate the results and paper numbers. If nursery and kindergarten should both count as no formal schooling, change the shared subgroup recode to `1/3`, rerun every affected result, and describe that definition explicitly.
