## Findings

### 1. The diagnostic misclassifies every labeled non-target record as absent from the labeled census

`target-only-flags-break-membership-diagnostic` · **MAJOR** · correctness · confidence: **verified** (traced in source)

**Where:** `MATCHING/1c_tgt_divided_files.do:58-65, MATCHING/tgt_fallback_diag.do:18-21, MATCHING/tgt_fallback_diag.do:43-49, MATCHING/tgt_fallback_diag.do:75-89, review/briefs/2026-11-17-tgt-diag.md:6-7`

**What the code does**  
The optimized builder executes `keep if tgt` before saving `tgt_flag1940.dta`, so that file contains only target IDs. The diagnostic then loads those IDs, retains divided-file records with `_merge==1`, and labels them `Divided-file records not in census1940_all_labeled_data.dta`. `_merge==1` now means `not in the target-only flag`, which includes both genuinely absent records and every labeled record with `tgt==0`.

**Why it matters**  
The claimed diagnostic of the 4,819,575 records outside the labeled census is no longer computed. Its count and age/birthplace profile will instead be dominated by ordinary labeled non-target records, potentially misleading the decision about whether treating genuinely unmatched records as non-target is defensible. The counts in the brief imply that tens of millions could be misclassified, although the exact revised count requires the external data.

**How to check**  
Run the diagnostic once with `ids` constructed from all `histid` values in `census1940_all_labeled_data.dta` and once from `tgt_flag1940.dta`; compare `nn` and the age/birthplace tables. Alternatively, on one divided file, merge IDs separately against the complete labeled-ID list and the target-only flag, then count observations unmatched only in the latter.

**Suggested fix**  
In `tgt_fallback_diag.do`, construct `ids` directly from all `histid` values in `census1940_all_labeled_data.dta`, rename `histid` to `id`, and assert uniqueness before the merge. Keep `tgt_flag1940.dta` target-only for speed in the production builder, but do not use it as a proxy for census membership.
