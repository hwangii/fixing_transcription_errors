## Findings

### 1. Reverting create_figures_SSHA2025.do to own-file middle initials conflates link quality with validator re-transcription and inflates the headline 28% gain

`moving-validator-inflates-match-quality-gain` · **BLOCKER** · claims-vs-code · confidence: **verified** (traced in source)

**Where:** `CODE/create_figures_SSHA2025.do:70-87, CODE/create_figures_SSHA2025.do:203-228, replication/diagnostics/validation_fixed_initials.do:39-40, replication/results/validation_fixed_initials.tex:28-30, replication/results/validation_fixed_initials.tex:68-70, D:/repos/6638fa0fd89fbec05130caeb/DHTS-2026-10-12.tex:97-98, D:/repos/6638fa0fd89fbec05130caeb/DHTS-2026-10-12.tex:548-549`

**What the code does**  
CODE/create_figures_SSHA2025.do:73,83 reverts to own-file 1940 middle initials, computing validated_before = mi`beg_yr'==mi1940 using mi1940 from the Ancestry link file, and validated_after = mi`beg_yr'==mi1940 using mi1940 from the ML model link file. Lines 211-220 compute valGainTarget = 100*((sv_after/sv_before)-1) (= 27.8% -> 28%), which evaluates the percentage change when both the link partner and the 1940 validation standard change simultaneously.

**Why it matters**  
The paper (DHTS-2026-10-12.tex:97-98, 548-549) claims a 28 percent increase in match quality (65% to 84%) on discordant records, interpreting this as evidence that newly recovered links are genuine rather than spurious. However, diagnostic validation_fixed_initials.do shows that holding the 1940 initial fixed reduces the target-group gain to 16.0% under Ancestry (valGainAncTarget) and 11.5% under FamilySearch (valGainFsTarget). For 829,471 kept links pairing the exact same individuals, validation jumps from 63.4% to 79.2% simply because mi1940 was re-transcribed. Reverting the code produces an inflated metric where more than half of the apparent 19.4 percentage-point gain is driven by re-reading initials rather than link quality.

**How to check**  
Compare valGainTarget (28%) in replication/results/create_figures_SSHA2025.tex with valGainAncTarget (16.0%) and valGainFsTarget (11.5%) in replication/results/validation_fixed_initials.tex. In Stata on temp.dta, count records where linked_before==1 & linked_after==1 & id_A_before==id_A_after & validated_before!=validated_after; 165,580 identical kept links change validation status solely because mi1940 changed.

**Suggested fix**  
Retain one fixed 1940 middle initial across both link versions in CODE/create_figures_SSHA2025.do (such as Ancestry's mi1940_anc, as implemented in commit 8e8990d) and update the paper text at lines 98 and 548 to report the true fixed-initial gain (16.0% under Ancestry, 11.5% under FamilySearch). If the 28% moving-initial figure is kept, explicitly describe it as conflating link changes with middle-initial transcription changes and prominently report the decomposition into link composition vs initial re-reading.
