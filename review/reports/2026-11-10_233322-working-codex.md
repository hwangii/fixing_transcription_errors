## Findings

### 1. The driver calls a nonexistent path after completing the two-hour Stata run

`form-feed-breaks-table-generator-path` · **MAJOR** · replication · confidence: **verified** (traced in source)

**Where:** `replication/Run-MachineA.ps1:56`

**What the code does**  
The command is `python (Join-Path $repo "MATCHING\fs_draft_tables.py") $paper`, but the character displayed between `MATCHING` and `s_draft_tables.py` is byte `0x0C` (form feed), not a slash followed by `f`. PowerShell therefore constructs an illegal/nonexistent path rather than `MATCHING/fs_draft_tables.py`.

**Why it matters**  
Every Machine A reproduction now fails immediately after the lengthy Stata stage. The Section 4.3 draft tables and subsequent claim check are never run, so the advertised one-command reproduction is broken.

**How to check**  
Run `Format-Hex replication/Run-MachineA.ps1` and inspect offset `0x09F0`, which contains `... MATCHING 0C 73 ...`. Then compare `Test-Path (Join-Path (Resolve-Path .) 'MATCHING\fs_draft_tables.py')` with the path constructed from the current line.

**Suggested fix**  
Replace the form-feed character with a normal path separator so the argument is exactly `MATCHING\fs_draft_tables.py`, then run the driver through the Python step.

### 3. Checksum verification does not detect a divided-file shard removed from disk

`removed-shards-ignored-by-hash-check` · **minor** · replication · confidence: **verified** (traced in source)

**Where:** `replication/hash_inputs.py:68-73, replication/hash_inputs.py:114-133`

**What the code does**  
The current file list is built dynamically with `d.glob("norace*.dta")`, and check mode only tests `old.get(short(f)) != digest` for files still in that current list. It never computes manifest paths absent from the current list, so removal of one shard is omitted from verification and can still yield exit status 0.

**Why it matters**  
A partial divided-file collection can be reported unchanged after the manifest is regenerated. The Stata scripts likewise enumerate the surviving shards, so a missing state/partition is not rejected at preflight and can alter the fixed-initial rows used in Tables 9–11.

**How to check**  
On Machine A, run `python -c "import replication.hash_inputs as h; old=set(h.read_manifest()); cur={h.short(f) for f in h.input_list()}; print(sorted(old-cur))"`. After temporarily making one manifested shard unavailable, the command identifies it, whereas the present `--check` loop has no equivalent test.

**Suggested fix**  
Compare the full set of manifest paths with the current input set and fail on both `old-current` and `current-old`. Also assert the expected shard count per year, or store the authoritative shard list rather than accepting any nonempty glob.
