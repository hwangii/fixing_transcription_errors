### 2. The Old and New middle-initial validation columns change the validating transcription as well as the links

`moving-middle-initial-validator` · **MAJOR** · identification · confidence: **verified** (traced in source)

**Where:** `LINKAGE/code/01_abe_jw/linkage_analysis.do:242-254, LINKAGE/code/01_abe_jw/linkage_analysis.do:512, LINKAGE/code/02_hlink/linkage_analysis_newlinks.do:374-386, LINKAGE/code/02_hlink/linkage_analysis_newlinks.do:553`

**What the code does**  
For Old links, the code sets miv to mi_anc (Ancestry's 1940 middle initial), whereas for New links it sets miv to mi_ml (the ML model's 1940 middle initial), and computes count if mi1930 == mi1940. The resulting percentages are placed side by side as 'MI Match Rate (%)' in Panel A under 'Coverage and Link Quality' in both the ABE/JW and HLINK tables.

**Why it matters**  
In linkage methodology, middle-initial agreement serves as an out-of-sample validation of match correctness. By changing the 1940 middle-initial transcription between Old and New, the comparison conflates link-quality improvements with re-transcription differences. Even for identical linked pairs, the validation rate can increase solely because the ML model transcribed the 1940 middle initial differently. Neither the table row label nor the caption informs the reader that different validators are used.

**How to check**  
Run replication/diagnostics/validation_fixed_initials.do, which already demonstrates on the main sample that kept links (status == 1) cannot change validation status under a single fixed 1940 validator, and decomposes how much of the apparent gain is driven by re-reading vs link selection. Apply the same fixed-validator calculation to the JW and HLINK links.

**Suggested fix**  
Validate both Old and New links against a single fixed human 1940 middle initial (e.g. mi_anc or mi_fs), or explicitly relabel the row as 'Own-Transcription MI Match Rate (%)' with a clear table footnote explaining that the Old and New columns evaluate against different 1940 initial transcriptions.
