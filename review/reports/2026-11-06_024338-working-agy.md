## Findings

### 1. abeclean is still called and crashes with r(2000) when only one name field is populated or when a field lacks alphabetic characters

`abeclean-guard-fails-on-single-empty-or-nonalphabetic-name` · **MAJOR** · correctness · confidence: **likely** (implied, depends on unseen data)

**Where:** `MATCHING/1b_fs_divided_files.do:68-70, LINKAGE/code/01_abe_jw/reference/abeclean.ado:153-173, LINKAGE/code/01_abe_jw/reference/abeclean.ado:230-234`

**What the code does**  
The guard checks `quietly count if fs_namefrst!="" | fs_namelast!=""` and calls `abeclean fs_namefrst fs_namelast, ...` whenever `r(N) > 0`. However, inside `abeclean.ado`, the command iterates over each variable in `varlist` independently (`foreach oldvar of varlist `varlist'`), strips non-alphabetic characters via `ustrregexra(`var', "[^a-z ]", "")`, and executes `split `var', gen(`temp')` without error trapping. If either name field contains all empty strings or only non-alphabetic characters (e.g. punctuation or numbers) across all records in a birthplace file, `split` executes on an entirely empty variable and terminates execution with `r(2000)` ('no observations').

**Why it matters**  
While the guard succeeds for the placebo run (where both fields are initialized to empty strings), a substantive FamilySearch run over hundreds of birthplace files will halt whenever a birthplace has records with only a first name or only a last name, or where transcription artifacts leave no cleanable letters. Because `1b_fs_divided_files.do` processes birthplace files in a loop, a single failure aborts the entire divided-file preparation stage.

**How to check**  
In Stata, create a test dataset with `fs_namefrst=""`, `fs_namelast="smith"`, and `sex=1`, and run `abeclean fs_namefrst fs_namelast, sex(sex) initial(mi_fs) nicknames nonysiis`. Stata will halt with `no observations r(2000)`. Repeat with `fs_namefrst="."` and `fs_namelast="smith"` to confirm that punctuation-only strings similarly produce r(2000).

**Suggested fix**  
Clean each name component independently conditional on that specific component containing cleanable alphabetic characters, e.g.:
gen fs_namefrst_cleaned = ""
gen fs_namelast_cleaned = ""
gen mi_fs = ""
quietly count if ustrregexm(fs_namefrst, "[a-zA-Z]")
if r(N) > 0 abeclean fs_namefrst, sex(sex) initial(mi_fs) nicknames nonysiis
quietly count if ustrregexm(fs_namelast, "[a-zA-Z]")
if r(N) > 0 abeclean fs_namelast, sex(sex) nicknames nonysiis
Alternatively, update abeclean.ado so that split is guarded against empty variables.
