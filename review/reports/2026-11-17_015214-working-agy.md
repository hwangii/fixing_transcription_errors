### 1. The standalone divided-file builder overwrites the target flag before checking whether outputs exist

`target-flag-overwritten-before-preflight` · **minor** · replication · confidence: **verified** (traced in source)

**Where:** `MATCHING/1c_tgt_divided_files.do:31, MATCHING/1c_tgt_divided_files.do:48, MATCHING/1c_tgt_divided_files.do:53-58`

**What the code does**  
MATCHING/1c_tgt_divided_files.do executes 'save `\"`flags'\"', replace' at line 48 without any prior existence test. The subsequent preflight check at lines 53-58 only verifies 'direxists(st_local(\"dst\"))' and never checks whether tgt_flag1940.dta already exists, contradicting the comment at line 53 stating that both dst and the flag file must not exist yet.

**Why it matters**  
While the master driver MATCHING/_tgt_only_run.do guards the flag file at startup, invoking or resuming MATCHING/1c_tgt_divided_files.do directly will silently replace tgt_flag1940.dta. If divided_file1940_tgt_cleaned already exists, the script overwrites tgt_flag1940.dta and then aborts with error 602, leaving an updated flag file alongside older intermediate and linkage files.

**How to check**  
In Stata, execute MATCHING/1c_tgt_divided_files.do while divided_file1940_tgt_cleaned is already present on disk; verify that tgt_flag1940.dta has its timestamp updated and is overwritten before the script exits with error code 602. Inspection of lines 41-58 confirms no pre-existence check on flags precedes line 48.

**Suggested fix**  
Move the existence preflight checks before line 41. Verify with 'capture confirm file `\"`flags'\"'' and 'direxists(st_local(\"dst\"))' that neither tgt_flag1940.dta nor divided_file1940_tgt_cleaned exists before loading data or executing save, halting with error 602 if either is present.
