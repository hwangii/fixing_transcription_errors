# Ditto surnames: unusable output and the non-target loss

Generated by MATCHING/ditto_diag.do. Do not edit by hand.

49 model states, 1940, all records in merged_data.dta. One filename is one 40-line half sheet. A chain is a head row (a model non-ditto, a missing flag, or a link break) and the model-ditto rows linked below it, following the schedule from row 40 of one image to row 1 of the next image of the same roll. The model's own ditto resolution (namelast_ml_ditto) carries the head's model surname down the chain, across images within a roll. Head-human fill = where the model surname is empty on a ditto row, use the head's surname when Ancestry and FamilySearch agree on the head. The literal 'InvalidPred' is treated as empty except in section 4. The fill is scored against the linking baseline: an empty model field falls back to the record's own Ancestry value (the actual pipeline is sentinel-blind and would link on 'invalidpred' for the sentinel rows). Names are compared as raw strings before abeclean, so a difference here is an upper bound on a change in the linked name; the linkage-level test is the ABE rerun. All labels are agreement with the two human transcriptions, not truth; the external reference is the FamilySearch-profile comparison, itself a selected sample. Universes as compute_model_agreement_on_discordant.do: HC = all four human name fields present; target = HC and Ancestry differs from FamilySearch on a name; non-target = HC and the humans agree on both names.
